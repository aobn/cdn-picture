# 图床项目数据库表设计

## 数据库概述

使用 **Turso (libSQL)** 作为云数据库，支持 SQLite 语法。

## 表结构设计

### 1. 图片表 (images)

存储上传的图片信息

```sql
CREATE TABLE images (
  id TEXT PRIMARY KEY,                    -- 图片唯一ID
  filename TEXT NOT NULL,                 -- 存储文件名
  original_name TEXT NOT NULL,            -- 原始文件名
  file_size INTEGER NOT NULL,             -- 文件大小(字节)
  mime_type TEXT NOT NULL,                -- MIME类型
  url TEXT NOT NULL,                      -- 访问URL
  thumbnail_url TEXT,                     -- 缩略图URL
  width INTEGER,                          -- 图片宽度
  height INTEGER,                         -- 图片高度
  upload_time DATETIME DEFAULT CURRENT_TIMESTAMP, -- 上传时间
  status TEXT DEFAULT 'active',           -- 状态: active/deleted/processing
  user_id TEXT,                           -- 用户ID(预留)
  album_id TEXT,                          -- 相册ID(预留)
  tags TEXT,                              -- 标签(JSON格式)
  description TEXT,                       -- 图片描述
  view_count INTEGER DEFAULT 0,           -- 查看次数
  download_count INTEGER DEFAULT 0        -- 下载次数
);
```

### 2. 相册表 (albums)

图片分类管理

```sql
CREATE TABLE albums (
  id TEXT PRIMARY KEY,                    -- 相册ID
  name TEXT NOT NULL,                     -- 相册名称
  description TEXT,                       -- 相册描述
  cover_image_id TEXT,                    -- 封面图片ID
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP, -- 创建时间
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP, -- 更新时间
  status TEXT DEFAULT 'active',           -- 状态
  user_id TEXT,                           -- 用户ID
  is_public BOOLEAN DEFAULT 1,            -- 是否公开
  sort_order INTEGER DEFAULT 0            -- 排序
);
```

### 3. 用户表 (users)

用户管理(预留功能)

```sql
CREATE TABLE users (
  id TEXT PRIMARY KEY,                    -- 用户ID
  username TEXT UNIQUE NOT NULL,          -- 用户名
  email TEXT UNIQUE,                      -- 邮箱
  password_hash TEXT,                     -- 密码哈希
  avatar_url TEXT,                        -- 头像URL
  create_time DATETIME DEFAULT CURRENT_TIMESTAMP, -- 注册时间
  last_login DATETIME,                    -- 最后登录时间
  status TEXT DEFAULT 'active',           -- 状态
  role TEXT DEFAULT 'user',               -- 角色: admin/user
  storage_used INTEGER DEFAULT 0,         -- 已使用存储空间
  storage_limit INTEGER DEFAULT 1073741824 -- 存储限制(1GB)
);
```

### 4. 上传记录表 (upload_logs)

上传操作日志

```sql
CREATE TABLE upload_logs (
  id INTEGER PRIMARY KEY AUTOINCREMENT,  -- 日志ID
  image_id TEXT,                          -- 图片ID
  user_id TEXT,                           -- 用户ID
  ip_address TEXT,                        -- IP地址
  user_agent TEXT,                        -- 用户代理
  upload_time DATETIME DEFAULT CURRENT_TIMESTAMP, -- 上传时间
  file_size INTEGER,                      -- 文件大小
  status TEXT,                            -- 上传状态: success/failed
  error_message TEXT                      -- 错误信息
);
```

### 5. 系统配置表 (settings)

系统配置信息

```sql
CREATE TABLE settings (
  key TEXT PRIMARY KEY,                   -- 配置键
  value TEXT,                             -- 配置值
  description TEXT,                       -- 配置描述
  update_time DATETIME DEFAULT CURRENT_TIMESTAMP -- 更新时间
);
```

## 索引设计

```sql
-- 图片表索引
CREATE INDEX idx_images_upload_time ON images(upload_time DESC);
CREATE INDEX idx_images_status ON images(status);
CREATE INDEX idx_images_user_id ON images(user_id);
CREATE INDEX idx_images_album_id ON images(album_id);

-- 相册表索引
CREATE INDEX idx_albums_user_id ON albums(user_id);
CREATE INDEX idx_albums_status ON albums(status);

-- 用户表索引
CREATE INDEX idx_users_username ON users(username);
CREATE INDEX idx_users_email ON users(email);

-- 上传日志索引
CREATE INDEX idx_upload_logs_image_id ON upload_logs(image_id);
CREATE INDEX idx_upload_logs_user_id ON upload_logs(user_id);
CREATE INDEX idx_upload_logs_upload_time ON upload_logs(upload_time DESC);
```

## 数据关系

1. **images.album_id** → **albums.id** (多对一)
2. **images.user_id** → **users.id** (多对一)
3. **albums.user_id** → **users.id** (多对一)
4. **albums.cover_image_id** → **images.id** (一对一)
5. **upload_logs.image_id** → **images.id** (一对多)
6. **upload_logs.user_id** → **users.id** (多对一)

## 查询示例

### 获取最新上传的图片
```sql
SELECT * FROM images 
WHERE status = 'active' 
ORDER BY upload_time DESC 
LIMIT 20;
```

### 获取用户的相册列表
```sql
SELECT a.*, COUNT(i.id) as image_count
FROM albums a
LEFT JOIN images i ON a.id = i.album_id AND i.status = 'active'
WHERE a.user_id = ? AND a.status = 'active'
GROUP BY a.id
ORDER BY a.sort_order, a.create_time DESC;
```

### 获取热门图片
```sql
SELECT * FROM images 
WHERE status = 'active' 
ORDER BY view_count DESC, upload_time DESC 
LIMIT 20;
```

### 统计信息查询
```sql
SELECT 
  COUNT(*) as total_images,
  SUM(file_size) as total_size,
  COUNT(CASE WHEN DATE(upload_time) = DATE('now') THEN 1 END) as today_uploads
FROM images 
WHERE status = 'active';
```

## 数据维护

### 清理删除的图片
```sql
DELETE FROM images 
WHERE status = 'deleted' 
AND upload_time < datetime('now', '-30 days');
```

### 更新统计信息
```sql
UPDATE users 
SET storage_used = (
  SELECT COALESCE(SUM(file_size), 0) 
  FROM images 
  WHERE user_id = users.id AND status = 'active'
);
