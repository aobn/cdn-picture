# 简单图片上传页面 UI 设计

## 页面概述

基于 TypeScript + React + shadcn/ui + Tailwind CSS 的简洁图片上传页面，专注于核心上传功能。


## 详细页面设计

### 1. Header 区域

```markdown
┌─────────────────────────────────────────────────────────┐
│  📷 图床上传                              🌙 [主题切换]   │
└─────────────────────────────────────────────────────────┘
```

**组件使用：**
- Logo 文字 + 图标
- `ModeToggle` 组件 - 主题切换按钮

### 2. 主上传区域

#### 2.1 拖拽上传区 (核心功能)

```markdown
┌─────────────────────────────────────────────────────────┐
│                                                         │
│                        📤                              │
│                                                         │
│                 拖拽图片到此处上传                        │
│                   或点击选择文件                         │
│                                                         │
│              支持 JPG, PNG, GIF, WebP                   │
│                   单个文件最大 10MB                      │
│                                                         │
│                   [选择文件按钮]                         │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

**组件使用：**
- `Card` - 上传区域容器
- `Button` - 选择文件按钮
- 自定义拖拽区域样式

## 响应式设计

### 桌面端 (≥1024px)
```markdown
- 上传区域: 最大宽度 800px，居中显示
- 文件列表: 单列布局
- 按钮: 完整文字显示
```

### 平板端 (768px - 1023px)
```markdown
- 上传区域: 适应容器宽度
- 文件列表: 单列布局
- 按钮: 完整文字显示
```

### 移动端 (<768px)
```markdown
- 上传区域: 全宽显示，减小高度
- 文件列表: 紧凑布局
- 按钮: 图标 + 简短文字
```

## 交互设计

### 拖拽交互
```markdown
1. 拖拽进入: 边框高亮，背景色变化
2. 拖拽悬停: 虚线边框，提示文字变化
3. 拖拽离开: 恢复初始状态
4. 文件放下: 立即显示文件列表
```

### 上传交互
```markdown
1. 文件验证: 格式、大小检查
2. 进度显示: 实时进度条更新
3. 错误处理: Toast 错误提示
4. 成功反馈: 绿色成功提示
```

## 组件实现清单

### 基础组件 (来自 src/components/ui)
- `Card` - 容器组件
- `Button` - 按钮组件
- `Progress` - 进度条
- `Input` - 输入框 (显示链接)
- `Badge` - 状态标识
- `Separator` - 分隔线

### 反馈组件
- `Toast` (Sonner) - 消息提示
- `AlertDialog` - 确认对话框 (清空列表时)

### 布局组件
- `ModeToggle` - 主题切换 (来自 layout 目录)

## 样式规范

### 颜色方案
```css
/* 上传区域 */
.upload-area {
  border: 2px dashed hsl(var(--border));
  background: hsl(var(--muted));
}

.upload-area.dragover {
  border-color: hsl(var(--primary));
  background: hsl(var(--primary/10));
}

/* 进度条颜色 */
.progress-success { background: hsl(var(--success)); }
.progress-error { background: hsl(var(--destructive)); }
```

### 动画效果
```css
/* 拖拽状态切换 */
.upload-area {
  transition: all 0.2s ease-in-out;
}

/* 文件列表进入动画 */
.file-item {
  animation: slideIn 0.3s ease-out;
}

/* 进度条动画 */
.progress-bar {
  transition: width 0.3s ease-out;
}
```

## 错误处理

### 文件验证错误
```markdown
- 格式不支持: "不支持的文件格式，请选择 JPG、PNG、GIF 或 WebP 格式"
- 文件过大: "文件大小超过 10MB 限制"
- 文件损坏: "文件可能已损坏，请重新选择"
```

### 上传错误
```markdown
- 网络错误: "网络连接失败，请检查网络后重试"
- 服务器错误: "服务器繁忙，请稍后重试"
- 存储空间不足: "存储空间不足，请清理后重试"
```

## 性能优化

### 文件处理
```markdown
- 图片预览: 生成缩略图预览
- 批量上传: 控制并发数量 (最多3个)

- 内存管理: 及时释放文件对象
```

### 用户体验
```markdown
- 即时反馈: 文件选择后立即显示
- 进度可视: 实时上传进度
- 操作撤销: 支持取消上传
- 状态保持: 页面刷新后恢复状态
```
